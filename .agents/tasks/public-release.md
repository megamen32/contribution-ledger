# Публикация Вклад и клиенты
Результат: присланный web-интерфейс на https://vklad.bezrabotnyi.com, клиенты Mac M1 и Windows.
Проверка: внешний HTTPS с валидным сертификатом, отказ без пароля, реальный вход и денежная операция в отдельной тестовой базе, запуск приложения на Mac.
Минимальный срез: один Node-сервер с SQLite и Nginx, существующий Swift-клиент, тонкий Windows-клиент.
Не строим: собственный OCR, новый движок захвата, синтетический консорциум, дублирующую базу на клиентах.
Исходник: workspace (1).tar; SHA256 cf709c0a7a080d003a926ebf86db9287b4e91064f845992e94d254aff5e6094c.
Не переносим: .env, демо-базу и git архива. Старый пилот 8766 сохранён.
