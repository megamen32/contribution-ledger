# Самостоятельная регистрация и проекты

Регистрация без приглашения атомарно создаёт проект, правила, профиль моделей и владельца. Регистрация по ссылке атомарно расходует приглашение и добавляет участника в тот же проект. Логины уникальны; конфликт откатывает создание проекта и расход приглашения. Аккаунт принадлежит одному проекту. Владелец видит название и ссылку «Пригласить участника»; приглашение доступно из аккаунта. Footer ведёт на публичный GitHub во всех основных состояниях.

Прежние записи остаются в legacy. Добавочная SQLite-миграция выполнена с защищённой SQLite backup; сравнение исходных колонок всех прежних таблиц подтвердило неизменность данных и триггеров, integrity_check=ok. Подтверждённые финансовые записи не переписывались. Прежние accepted business keys сохраняют запись при повторе; новые ручные ключи разделены по проекту и автору.

Проверки: RED регистрации без invite (422 вместо 201), затем GREEN SQLite + настоящих route handlers: два проекта, приглашение, reuse/expiry, дубликат без orphan, отдельные суммы, задачи, конфигурация, запрет foreign-ID финансовых и отчётных операций. Legacy migration rerun сохранён. TypeScript и bounded production build прошли. Настоящие HTTP owner-setup/password-policy прогоны прошли, включая вход и смену пароля. Сборка: четыре CPU/workers, 6 GiB RAM, 1 GiB swap, 256 tasks, deadline 120 s; обычный release run уложился в 180 s. Медленный nightly не требовался.

Пользовательская приёмка через штатный AgentBrowser MCP server-44: демо → регистрация владельца A без invite → проект A → приглашение → новый участник A → два участника одной команды; самостоятельный владелец B → отдельный проект B → задача через настоящий UI. Публикация пробной карточки B и чтение из аккаунта A подтвердили отсутствие карточки в общей доске и 404 прямого чужого ID. Footer открыл GitHub с публичным репозиторием и правильным заголовком без авторизации.

В приёмке встретился пустой about:blank из-за разных параметров idleTimeout между MCP-вызовами. До повтора сохранён и просмотрен screenshot из той же сессии; одинаковый idleTimeout во всех вызовах восстановил устойчивый маршрут. Продуктовая регистрация до этого не вызывалась. Работали только на server-44; собственная сессия закрыта. Пароли и приглашения не включены в скриншоты/документы Git. Рабочие screenshots и exact receipts только в игнорируемой .tmp/projects-signup/. После подтверждённого результата удалены лишь три собственных QA-аккаунта, два QA-проекта и одна задача, при проверенном отсутствии денег, сессий и неизвестной работы. Исходная команда сохранена.
