# Contribution Ledger: Ponytail / honest team
Implement the smallest usable slice, never a new specification instead of working code.
Default branch main. Each completed change: tests, scoped commit, push, deploy, live smoke.
Preserve unrelated work. Never commit credentials, working records, screenshots or personal data.
Reuse tested contribution_spec accounting; one FastAPI process, SQLite, persistent jobs, native HTML.
No Ollama. OmniRoute only: minimax/MiniMax-M3 summaries; glm-5.3 and gpt-6 judges, three runs each.
Model IDs must be verified against the actual router; record requested and returned models.
Screenpipe is the capture engine. Do not implement another screenshot/OCR engine. ONNX is optional
only after a failing Screenpipe OCR canary. Firecrawl AnyDoc is optional document extraction, not OCR.
Effort credit is ON by default: confirmed work × agreed rate, no inactivity penalty. Opt-out requires
an explicit result value, never an automatic zero or a secretly changed AI valuation.
Do not change company equity or assign morality/reputation scores.
Missing capabilities remain visibly unverified. No claim that a mock proves real recording Stop.
Screenpipe license/subscription is a separate prerequisite; do not bundle proprietary builds.
Binary delivery: tested builds only, platform-specific. Do not claim a Linux binary is a Mac installer.
