## Развёртывание
Новая версия web из присланного архива развернута на server-100, сервис vklad-web.service, внутренний порт 127.0.0.1:8768. SQLite: /home/roomhacker/.local/share/vklad/ledger.db. Демонстрационная база из архива не импортирована. Старый пилот на 8766 оставлен без удаления.
Поддомен уже разрешался через DNS; приобретение домена и новая DNS-запись не требовались. Новый HTTPS-vhost добавлен через канонический nginx-dev. Сертификат Let's Encrypt выпущен до 2026-12-06, установлен штатный механизм продления. Пробное продление отдельно не выполнялось.
Корень и API защищены существующим входом auth.bezrabotnyi.com. Страница скачивания публична и не содержит ключей. Отдельные приглашения и доступы коллегам ещё не выдавались. Выбор участника внутри приложения — доверенный командный режим, не разграничение личных данных.

## Проверено
- Строгая TypeScript-проверка и production build Next.js.
- 5 регрессионных тестов, 19 утверждений: деньги, отмены, идемпотентность, незавершённые оценки, подмена модели.
- 9 сквозных HTTP-проверок на отдельной test.db: участник, ставка, 90 минут = 1500 рублей, деньги + труд = 3500 рублей, повтор, выплата и отмена, новая ставка без пересчёта прошлого, новая работа по новой ставке, запрет чужого Origin.
- Реальный браузер: новый интерфейс и форма добавления первого участника, без записей в рабочую базу.
- Внешняя сеть vpn2: HTTPS health=ok, API без входа перенаправляется на авторизацию, установщики и SHA256 доступны.
- Mac M1: arm64-сборка, 25 проверок адресов/SSO, живая отрисовка HTTPS-страницы авторизации в WebKit, образ скачан через общий адрес, контрольная сумма совпала. /Applications/Vklad.app обновлён до 0.2.0 без закрытия прежнего окна. Старая копия сохранена в ~/Library/Caches/vklad-release-0.2.0/previous-Vklad.app.
- Windows: сборка PE x64 и go vet выполнены; живого запуска Windows не было. В ZIP включены лицензии зависимостей.

## Границы выпуска
Это клиенты общего кабинета, НЕ система записи экрана. Screenpipe и единый Start/Stop захвата ещё не подключены. Клиенты не получают доступ к экрану или клавишам.
Живые модели OmniRoute и суммаризация MiniMax ещё не проверены и не подключены серверным API-ключом. Реальные маршруты glm-5.3/gpt-6 подготовлены, подставные тесты не выдаются за реальные оценки. Финансовые записи не зависят от оценки ИИ.
Mac-сборка имеет локальную ad-hoc подпись, без нотарификации Apple. Windows — без подписи издателя, требуется WebView2 Runtime. Полная авторизованная UI-сессия через общий SSO не прогонялась.
Резервное копирование новой базы на отдельное устройство и подключение диска 3 ТБ в этом выпуске не выполнены.
