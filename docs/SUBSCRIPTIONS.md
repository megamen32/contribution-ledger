# Оценки задач через подписки

Рабочий кабинет может оценивать утверждённый автором отчёт двумя настоящими моделями: `glm-5.3-flash` через Z.AI Coding Plan и `MiniMax-M3.1-Flash-Preview` через MiniMax M Plan. Каждая модель выполняет три отдельных прогона. Ответы проверяются по схеме, ссылки на источники — по обезличенному пакету. Оценка ИИ не создаёт финансовую запись.

Для собственного сервера задайте `VKLAD_LLM_MODE=subscription`, `VKLAD_GLM_KEY_FILE` и `VKLAD_MINIMAX_KEY_FILE` — пути к отдельным защищённым файлам ключей. Ключи находятся только на сервере и не отправляются браузеру. Для разработки без подписочного режима остаётся прежний адаптер OmniRoute. В подписочном режиме скрытого переключения на другой шлюз нет.

Используются Anthropic-compatible endpoints: Z.AI `https://api.z.ai/api/anthropic/v1/messages` и MiniMax `https://api.minimax.io/anthropic/v1/messages`. Запрошенная и возвращённая модели должны совпасть; thinking-блоки не считаются ответом, обрезанный или некорректный JSON не засчитывается. Сохранённая оценка содержит provider, request ID, provider response ID, usage и исходный ответ. HTTP-ошибка не приводит к автоматическому повтору.

Без подходящего рыночного справочника цена отображается как неизвестная, а не как ноль. Согласованная ставка труда и его учёт независимы от оценки ИИ.

Демо — локальный заполненный кабинет с вымышленными участниками, задачами и вкладами. Его изменения сбрасываются к исходным примерам при перезагрузке или кнопкой «Сбросить демо». Демо не делает запросы к моделям, не записывает экран и не читает рабочие данные.

Официальные источники: [Z.AI Coding Plan](https://docs.z.ai/devpack/overview), [Z.AI Anthropic interface](https://docs.z.ai/devpack/tool/claude), [MiniMax Anthropic API](https://platform.minimax.io/docs/api-reference/text-anthropic-api). Названия и доступ проверены 13 октября 2026; состав подписок может измениться.
