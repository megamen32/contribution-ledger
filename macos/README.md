# Вклад 0.2.1 — macOS Apple Silicon

Перетащите Vklad.app в Программы. Общий адрес: https://vklad.bezrabotnyi.com
У каждого участника свой логин и пароль Вклада; личный админский SSO не используется. База на сервере 100; клиент не создаёт вторую базу.
Приложение не записывает экран. Screenpipe ещё не подключён.
Сборка arm64, macOS 13+, ad-hoc подпись без нотарификации Apple. Защиту macOS отключать не нужно.
Бинарник не содержит паролей или ключей OmniRoute.
