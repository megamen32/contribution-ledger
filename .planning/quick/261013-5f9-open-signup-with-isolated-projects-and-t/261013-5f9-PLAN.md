1. Добавить проект к участникам и политике/профилям, перенести прежнюю команду в legacy без потери записей.
2. Публичная регистрация атомарно создаёт проект + владельца; приглашение атомарно создаёт участника существующего проекта. Дубликаты и повторное приглашение не оставляют лишних проектов.
3. Ограничить списки, сводки и операции рамками проекта и существующей личной приватности. Показать проект и приглашения владельцу, публичный GitHub в footer.
4. Проверить SQLite и настоящие API (focused integration, expected 10 s, max 30 s); typecheck/build (focused integration, expected 50 s, max 120 s); release run max 180 s. Доставить и пройти в штатном браузере server-44: демо → владелец → проект → приглашение → участник; второй проект изолирован.

Источники: существующие auth/account/ledger routes и Prisma schema. Только canonical main; данные и тестовые пароли вне Git. Старые результаты сохраняются.
