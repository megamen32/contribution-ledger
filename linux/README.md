# Вклад для Ubuntu 22.04 / amd64

Скачайте .deb и установите его: `sudo apt install ./Vklad-Ubuntu-amd64-v0.3.2.deb`.
В меню приложений появится «Вклад» с иконкой весов.

Кабинет работает на https://vklad.bezrabotnyi.com. В приложении доступны демо,
вход и ваши проекты. «Начать запись» запускает вложенный MIT Screenpipe,
«Остановить» завершает его и сохраняет запись локально. Автоматической записи,
записи аудио или отправки снимков нет. «Записи» открывает локальную папку.

Запись этой версии проверяется в X11. Для Wayland войдите в сеанс Ubuntu on Xorg.
Веб-таймер начислений учитывается отдельно от локальной записи.

Автоматическая проверка настоящего клиента: `bash linux/smoke.sh /path/to/packaged/client /absolute/evidence`.
Она открывает отдельный тестовый рабочий стол, загружает кабинет, нажимает те же
кнопки запуска/остановки, проверяет настоящий кадр, OCR-маркер и строки SQLite,
завершение процесса и отсутствие новых кадров после Stop. Чужой экран не снимается.

Сборка: закреплённый source.json + Cargo.lock Screenpipe; GTK/WebKit системные.
Клиент ограничен 2 GiB RAM, без swap, 2 CPU, 128 задач, IOWeight50. Это общий
бюджет окна, WebKit и Screenpipe; запись прекращается при закрытии клиента.

Ubuntu 0.3.2 добавляет «Сводка и оценка»: после Stop просмотрите OCR-выдержки,
выберите собственную задачу и создайте черновик. Отдельная кнопка утверждает
отчёт и запускает оценку 2×3 по настроенным подпискам. Изображения остаются
локально. Ответ и расход сохраняются рядом с записью. Цена отдельного вызова
по подписке провайдером не сообщается; неизвестная цена не равна нулю.
