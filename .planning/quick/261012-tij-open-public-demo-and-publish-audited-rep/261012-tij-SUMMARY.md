# Демо и публикация доставлены

Главная для анонимного посетителя показывает отдельную интерактивную песочницу; /demo доступен также пользователю с аккаунтом. Пробные записи живут только до перезагрузки. API команды не раскрывается гостю. Mac arm64 0.3.0 скачивается напрямую; предложение аккаунта открывает существующую регистрацию по приглашению. Публичные исходники доступны на https://github.com/megamen32/contribution-ledger.

Проверки: TypeScript и production build прошли; существующая быстрая password-policy проверка прошла. Исправлены ранее отсутствовавшие bun-types в конфигурации TypeScript и тип тестового fetch mock. Сборка использует existing NEXTAUTH_SECRET_FILE без копирования значения. Доступные четыре CPU ограничены taskset, heap 4 GiB, timeout 120 s; сборка завершилась в лимите. Отдельный первоначальный диагностический build без secret-file отказал до генерации страниц; этот отказ не считается успешным.

Живой headed Chrome: анонимная главная без перенаправления, 2 часа по 1000 ₽ + 1000 ₽ денег = 3000 ₽, создание и завершение задачи, общий итог, сброс, повторное открытие с пустым состоянием, отрицательные часы отклоняются без записи, переход к форме регистрации. Мобильный viewport 390 × 844 визуально проверен. /api/me, /api/ledger, /api/tasks для гостя дают 401. GET range macOS DMG дал 206 с 1024 байтами. GitHub API без credentials подтверждает private=false.

Секреты: Gitleaks 8.30.1 проверил все Git refs/историю, publishable файлы, архив исходников v0.1.0, строки содержимого Linux/Mac/Windows ZIP/TAR релизов и публичные метаданные; утечек не обнаружено. Приватный временный clone token из служебного ответа GitHub и случайные Next.js build tokens находятся только в игнорируемых диагностических файлах и не публикуются.

Скриншоты и snapshots сохранены только в игнорируемой .tmp/public-demo/, не входят в Git. Начальные попытки браузера на сервере без X display не создали страницу: screenshot был невозможен. Проверка выполнена после запуска отдельного собственного Xvfb/Chrome. Личная командная база не изменялась.

Клиенты не пересобирались; существующий Mac download предназначен для Apple Silicon. Демо не запускает Screenpipe и модели ИИ. Новая open self-signup регистрация не добавлялась: действуют приглашения команды.
