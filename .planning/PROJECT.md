# Вклад

## What This Is
Вклад учитывает труд и денежные вложения команды. Существующий Next.js кабинет и нативные клиенты дополняются открытым демо для знакомства без аккаунта.

## Core Value
Посетитель может попробовать учёт вкладов до регистрации.

## Requirements
### Validated
- Существующий кабинет, отдельные учётные записи и Mac-клиент поставлены ранее; исторические ограничения сохранены в docs/.
### Active
- [x] Открыть интерактивное демо без регистрации.
- [x] Предложить аккаунт после знакомства и скачивание macOS.
- [x] Проверить публичную Git-историю на секреты и сделать репозиторий публичным.
### Out of Scope
- Пересборка клиентов и изменение движка записи экрана — не запрошены.

## Context
Источник: README.md, docs/STATUS.md, deploy/vklad-web.service. Реальный кабинет хранит записи отдельно от исходников.

## Constraints
- Существующий main, только свои изменения.
- Демо не читает и не изменяет личные данные команды.
- Существующий macOS arm64 0.3.0 доступен в /downloads/.
