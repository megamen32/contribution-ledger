# Вклад 0.3.0 — Mac Apple Silicon

Screenpipe входит в Vklad.app. Отдельная установка Screenpipe, Rust, Python,
Ollama или моделей не требуется. Общий кабинет: https://vklad.bezrabotnyi.com

Верхняя кнопка «Начать запись» запускает локальную сессию Screenpipe.
При первом запуске разрешите Vklad запись экрана в настройках macOS:
Конфиденциальность и безопасность → Запись экрана и системного аудио.
Системный раздел так называется; приложение не записывает аудио.
После разрешения при необходимости перезапустите Vklad и нажмите кнопку снова.

«Остановить» завершает процесс записи. До подтверждения завершения показывается
«Останавливается запись». Закрытие приложения, сон или блокировка также
запрашивают остановку; после следующего запуска запись сама не включается.

«Записи» открывает локальную папку сессий. Исходные снимки, извлечённый текст
и база Screenpipe остаются на этом Mac. Автоматической отправки пока нет.
В этом выпуске нативная запись ещё не связана с веб-таймером начисления труда.

Сборка использует собственный форк megamen32/screenpipe с MIT-кодом до смены
лицензии. Исходная версия, проверочные суммы и уведомления зависимостей лежат
в Contents/Resources/Screenpipe. Коммерческая директория ee/ не включена.

Проверено: сборка ARM64 на M1/macOS 26.6, реальный Screenpipe OCR и запись
тестового кадра в его базу, отсутствие внешних библиотек Homebrew у бинарника,
подпись приложения, запуск кабинета без автоматической записи.
Запись настоящего экрана и её остановка требуют выданного пользователем
разрешения macOS и отдельной живой проверки. Более старые macOS не проверены.

Сборка имеет ad-hoc подпись, не нотарифицирована Apple. Защиту macOS отключать
не нужно. Никаких паролей, ключей моделей или записей команды в пакете нет.

Для разработчика: собрать форк по закреплённому macos/screenpipe-source.json,
затем SCREENPIPE_BUNDLE_DIR=/path/to/screenpipe/vklad/bundle bash macos/build.sh.
Пакет без настоящего закреплённого бинарника Screenpipe не собирается.
