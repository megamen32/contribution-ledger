# Вклад

Учёт труда и денежных вложений команды: посмотрите, кто сколько вложил, по согласованным ставкам и без подмены вклада долей в компании.

- Рабочие записи, задачи и денежные вложения в одном кабинете.
- Труд учитывается по согласованной часовой ставке.
- Отдельные аккаунты участников и общая таблица вкладов.
- Mac-клиент с локальной записью Screenpipe, запускаемой пользователем.

[Попробовать демо без регистрации](https://vklad.bezrabotnyi.com/) · [Скачать для macOS](https://vklad.bezrabotnyi.com/downloads/Vklad-macOS-arm64-v0.3.0.dmg) · [Все загрузки](https://vklad.bezrabotnyi.com/downloads/)

## Начать

Демо работает сразу в браузере. Добавьте пробную работу или деньги, посмотрите итог и создайте аккаунт и свой проект, когда будете готовы. Пригласите участников ссылкой из своего кабинета. Пробные записи остаются только в открытой вкладке до перезагрузки и не переносятся в командный кабинет.

Mac: скачайте образ, откройте его и перетащите Vklad.app в «Программы». Можно скачать из терминала:

```sh
curl -fLO https://vklad.bezrabotnyi.com/downloads/Vklad-macOS-arm64-v0.3.0.dmg
```

Сборка 0.3.0 предназначена для Apple Silicon. Она не нотарифицирована Apple. Запись экрана требует разрешения macOS, остаётся на вашем Mac и не запускается автоматически.
