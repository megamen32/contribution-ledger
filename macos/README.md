# Вклад для Mac · 0.1.1 · Apple Silicon

Нативный клиент на Swift + системный WebKit. Открывает уже работающий сервер команды.
Это не Linux-бинарник и не отдельная локальная база.
Python, Node, Electron и Ollama для запуска не требуются. Rosetta не нужна.

## Установка

Откройте Vklad-macOS-arm64-v0.1.1.dmg, перенесите Vklad.app в «Программы».
По умолчанию приложение подключается к http://192.168.2.100:8766.
Нужна связь с сервером через локальную сеть или VPN. Адрес меняется кнопкой «Сервер» / Cmd+,.
Войдите с ключом команды; сессия хранится в собственном WebKit-профиле приложения.
Ключи команды и OmniRoute НЕ встроены в приложение или установщик.

Сборка подписана локальной ad-hoc подписью. Developer ID и нотариального заверения Apple нет.
На другой машине скачанная копия может потребовать подтверждения в
«Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».
Не отключайте Gatekeeper и не снимайте защиту со всех приложений.
Для обычного массового распространения нужна Developer ID подпись и notarization.

## Что есть

Нативное окно, Cmd+C/V/A/R, настройка адреса, повтор подключения при ошибке.
Общий серверный учёт денег и времени, зачёт стараний по умолчанию и opt-out.
Выбор просмотренного JSON-экспорта Screenpipe через стандартное окно macOS.
Явное подтверждение отправки материалов.
Общие данные остаются на сервере; запуск приложения не создаёт вторую книгу вкладов.

## Границы этой поставки

Клиент не включает захват экрана. Его Start/Stop — таймер работы на сервере, не управление Screenpipe.
Закрытие окна НЕ останавливает серверный таймер. Screenpipe нужно устанавливать/настраивать отдельно.
Screenpipe, его платные бинарники, лицензия и ключи не включены в пакет.
Настройки OmniRoute остаются на сервере. Эта сборка сама по себе не устраняет недостающие права API.
Без сети доступ к общей базе недоступен; автономный сбор и синхронизация ещё не реализованы.

## Сборка и проверки

Требуется Apple Silicon Mac с Command Line Tools/Xcode. Прямых сторонних зависимостей нет.

bash macos/build.sh

dist/macos/Vklad.app/Contents/MacOS/Vklad --smoke-dir "$TMPDIR/vklad-smoke"

Smoke использует отдельное непостоянное хранилище cookies, проверяет фактический DOM рабочего
сервера и пишет result.json + window.png. Он НЕ проверяет запись Screenpipe или ответы моделей.
Фактически испытанная ОС и результаты конкретной сборки находятся в STATUS.md.

В приложенном пользователем Next.js-архиве обнаружены другой API и демонстрационная база.
Он не заменяет рабочий сервер автоматически: в src/lib/llm.ts три семейства имитируются
персонами одного вызова ZAI, а packetHash не является SHA-256. Эти механизмы не перенесены.

Источники API: https://developer.apple.com/documentation/webkit/wkwebview/
Подпись: https://developer.apple.com/developer-id/
