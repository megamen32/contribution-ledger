Ubuntu 22.04 · amd64

Скачать для Ubuntu

Версия 0.3.2, с иконкой и встроенным Screenpipe. Установите: sudo apt install ./Vklad-Ubuntu-amd64-v0.3.2.deb.

На Ubuntu автоматически проверены запуск кабинета, настоящий кадр, извлечённый текст, запись в SQLite и остановка процесса. Запись проверена в X11; для Wayland выберите Ubuntu on Xorg при входе.

Mac · Apple Silicon

Скачать для Mac · ZIP

Версия 0.3.1 с иконкой. Откройте образ и перетащите Vklad.app в «Программы».

Проверены ARM64, подпись, содержимое пакета и иконка. Запись настоящего экрана и Stop на Mac требуют отдельной проверки после разрешения macOS. Сборка не нотарифицирована Apple.

Windows · x64

Скачать прежний клиент 0.2.0Требует Edge WebView2. Пока открывает только кабинет, без встроенной записи; живой запуск на Windows не подтверждён.

Запись включается вами и сохраняется на вашем компьютере. Аудио не записывается, снимки автоматически не отправляются. На Ubuntu после Stop можно просмотреть распознанный текст, создать сводку выбранной задачи и отдельно утвердить её для оценки. Скриншоты остаются локально. Mac 0.3.1 пока сохраняет запись только локально. Начисления по веб-таймеру учитываются отдельно.
