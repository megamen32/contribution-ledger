## Остаётся неподтверждённым

- Живой OmniRoute: существующий MCP-ключ отказал execute:completions. Никакого обхода прав.
  HTTP key приложения ещё не настроен. GLM/GPT/MiniMax — точные запрошенные настройки,
  но действительные модельные ID, ответы, стоимость, качество и обход семантического кеша
  не проверены на реальном провайдере. Денежный учёт от этого не зависит.
- AI и импорт Screenpipe покрыты синтетическими тестами, не объявлены живыми E2E.
- Screenpipe на сервере не установлен; лицензия/сборка и устройства команды не проверены.
  Реализовано чтение локального /search за указанный интервал и ручное подтверждение импорта.
  Таймер приложения НЕ включает и НЕ выключает Screenpipe. Это явно написано в интерфейсе.
- macOS/Windows бинарники, подпись и установка пяти участникам не выполнены.
- Диск 3 ТБ не найден в проверенных монтированиях сервера. Архив экранов сюда не переносился.
  Резервное копирование на другой физический диск пока не настроено.
- graphify недоступен в PATH этой исполняющей среды; обновление графа не заявлено.

## Исправления, найденные реальным запуском

- init использовал Path.open(opener=...), что не поддерживается pathlib: исправлен единый
  вызов создания ключа, добавлен регрессионный тест сохранения ключа/прав.
- Первичная root-команда создала каталог данных от root. Владение исправлено только у
  двух новых путей приложения; systemd работает как roomhacker. Для следующих установок
  инициализация явно выполняется как сервисный пользователь, не как root.

Повторная проверка: uv sync --all-groups --frozen; uv run pytest -q;
uv run python scripts/smoke_binary.py. Smoke создаёт только отдельные синтетические данные.
